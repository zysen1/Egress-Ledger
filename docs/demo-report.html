Request body bytes are the HTTP body observed after TLS interception. HTTP request bytes are the reconstructed HTTP/1.1 message (request line, headers, body) and exclude TLS framing. Certificate-pinned handshakes that reject the ledger CA are recorded as invisible and contribute no bytes. Secret findings are regex hits on the body and on inflated git objects. Full-file findings are exact byte matches of workspace files of at least 48 bytes. Git findings are smart-HTTP routes and pack objects, including blobs named by trees in the same pack. Egress Ledger records traffic. It does not block it.

Invisible means the client opened a tunnel and rejected the ledger CA, which is what certificate pinning looks like from this proxy. Those bytes are not in the totals. Traffic that never used the proxy is outside this report.
